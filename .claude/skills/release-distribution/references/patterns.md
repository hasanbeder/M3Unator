# Approved Patterns — Release Distribution

### Pattern: Release sync checklist

```markdown
- Update `M3Unator.user.js`
- Update `M3Unator.meta.js`
- Update `CHANGELOG.md`
- Run validators
- Smoke install/update flow
```
