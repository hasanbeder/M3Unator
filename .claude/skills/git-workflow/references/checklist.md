# Pre-Commit Checklist — Git Workflow

## Automated

- [ ] `git diff --stat --cached` shows one primary concern

## Manual Review

- [ ] Branch name matches change type
- [ ] Release commits update runtime, metadata, and changelog together
- [ ] PR body names browsers and directory listing variants checked
- [ ] No unrelated screenshots or local artifacts are staged
- [ ] Reviewer can understand the change from the commit title alone
